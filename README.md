PocketPal is a rechargeable virtual pet, kind of like a Tamagotchi, that uses a floating hologram display.

The idea is to create a physical virtual pet that seems to float inside a clear box using the Pepper's Ghost trick.

Planned features include:
*   An animated pet
*   Actions like feeding, playing, and sleeping
*   Stats for hunger, happiness, and energy
*   Three physical buttons
*   Sound effects
*   Portable rechargeable power
*   A custom clear enclosure

For hardware, it uses an Arduino UNO R4 Minima, a Waveshare 2-inch LCD screen, a beam-splitter glass panel, tactile buttons, a buzzer, and a rechargeable 5V power system.

Right now, it's in the design and early building phase.

Here's the plan:
*   Get the LCD working with the Arduino.
*   Create the pet's animations.
*   Build the game's logic.
*   See if the beam-splitter reflection works as expected.
*   Design the case and parts to hold everything.
*   Add the rechargeable battery system.
*   Put it all together and test it.

This project was inspired by a tutorial on 'how to build a Tamagotchi'.
